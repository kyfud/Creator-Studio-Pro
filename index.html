GitHub Pages Par Free Website Host Kaise Kare?

Aap is pure tool ko bilkul free me GitHub par live kar sakte ho.

Step 1: Save `index.html` File

Is webpage ke pure code ko apne PC ya Mobile me index.html ke naam se save kar lo.

Step 2: GitHub me Account & Repository Banao

1. GitHub.com par jaakar free account banao.
2. Top right me + (Plus) icon par click karke New repository chuno.
3. Repository name rakho: yt-creator-tools aur Public select karo.

Step 3: `index.html` Upload Karo

1. "uploading an existing file" par click karo.
2. Apni index.html file drag & drop karo aur Commit changes par click karo.

Step 4: 1-Click Public Enable Karo

1. Repository ki Settings tab me jao.
2. Left menu se Pages par click karo.
3. Branch me main ya master select karke **Save** dabao.
🎉 1 minute ke andar aapki website live URL me mil jayegi!
